# Experiment 20: Complete CI/CD Pipeline & Deployment

## Learning Outcomes

Here are the 5 key learning outcomes from this experiment:

1. **End-to-End CI/CD Construction**: Developed and configured a complete Continuous Integration and Continuous Deployment (CI/CD) pipeline, automating the journey of code from local development to production.
2. **Automated Quality Gates**: Implemented strict CI workflow rules that block new changes from deploying unless all automated tests pass successfully, ensuring buggy code never reaches production.
3. **Cloud Deployment with Render**: Gained practical experience in deploying full-stack web applications and services to the Render cloud platform, utilizing its webhook-based automatic deployment triggers.
4. **SQL Database Integration**: Learned how to effectively configure and connect a production application to a live SQL database to persistently store, manage, and retrieve student records.
5. **Production Reliability Workflows**: Bridged the gap between local testing and production by building a reliable deployment process that prioritizes application stability, uptime, and automated rollouts upon verified commits.
